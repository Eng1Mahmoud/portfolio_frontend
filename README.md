# Portfolio Website

A modern, responsive portfolio website built with Next.js and TypeScript, featuring a dashboard for content management.

## 🚀 Technologies

- **Frontend Framework:**
  - Next.js 15 (App Router)
  - TypeScript
  - React 19
  - react-toastify


- **Styling & UI:**
  - Tailwind CSS
  - Framer Motion (for animations)
  - React Icons

- **Form Handling & Validation:**
  - react-hook-form (Form handling)
  - Zod (Schema validation)
  - Custom form components

- **Image Management:**
  - Next.js Image Optimization
  - Cloudinary Integration

- **Monitoring & Error Tracking:**
  - Sentry

## ✨ Features

- Responsive design
- Dashboard for content management
- Project showcase with demo and GitHub links
- Skills section
- Contact form
- Animated UI components
- Image optimization
- Form validation
- Error tracking
